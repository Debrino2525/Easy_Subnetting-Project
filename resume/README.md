## How to export PDF

1. Open `Richard_Kwame_Appiah_Resume.html` in Chrome, Edge, or Firefox.
2. Press **Ctrl+P** (or **Cmd+P** on Mac).
3. Set destination to **Save as PDF**, margins to **Default** or **None**, and enable **Background graphics** if available.
4. Save.
