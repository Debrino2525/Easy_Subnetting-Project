# Globitech Cyber Solutions

Marketing website for **Globitech Cyber Solutions** — a cybersecurity firm based in Takoradi, Western Region, Ghana.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
cd globitech-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Cloudflare (your domain)

Upload **only** `cloudflare-static/` (it contains `index.html`).  
Do not upload the TypeScript/Next.js project folder.

See [CLOUDFLARE.md](./CLOUDFLARE.md) for step-by-step instructions.

```bash
npm run sync:static
# then drag-and-drop cloudflare-static/ in Cloudflare Pages
# or: npm run deploy:cloudflare
```
