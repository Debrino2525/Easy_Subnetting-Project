# Globitech Cyber Solutions

Marketing website for **Globitech Cyber Solutions** — a cybersecurity firm based in Takoradi, Western Region, Ghana.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Develop

```bash
cd globitech-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
